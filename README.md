# EMR · Smart MDT demo

Pure front-end demo of an EMR with a Smart MDT module (tumour board, allied-health consults, case conferences, family meetings). No server, no network calls; everything runs in the browser and all patients, staff and data are fictitious.

- Demo: `index.html` (start the guided tour with `index.html?tour=1`)
- One-page guide (EN / 中文): `guide.html`
- Technical notes (中文): `README_demo.md`

MDT write actions in this demo are for demonstration only and are not part of the phase 1 scope. AI assistance, remote MDT and automatic enrolment are shown only as roadmap items.
