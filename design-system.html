SMART WARD · DESIGN SYSTEM

安靜、清楚、每個動作都有回應

病房工作站一天要看好幾百次。這套系統讓畫面先安靜下來，只把需要注意的東西提亮；所有值都來自 tokens.css，元件在 components.css，規格寫在 PRD_設計系統.md。這一頁直接讀實際的 CSS，改 token 這頁就跟著變。

安靜優先底色、框線與次要按鈕都是中性色；綠色只留給主要動作與選取狀態。
一眼分輕重一個區塊最多一顆主要按鈕；其餘降為次要、文字或圖示按鈕。
狀態不只靠顏色危險、警示、資訊都有圖示或文字；異常值同時有底色與 ▲▼ 標記。
回應在手邊存檔結果在畫面下方浮出；換頁時內容交叉淡入，側欄與頂列不動。

色彩

七組 OKLCH 色階由公司色票（綠葉、萊姆圓、藍色波浪）推出，每組 13 階，明度一致，所以同一階在不同色相看起來一樣亮。畫面上只用語意 token；色階只給 token 本身與圖表。

字型與字級

系統字：Windows 用 Segoe UI Variable 與微軟正黑體，Mac 用系統字與蘋方，越文走拉丁字型。不另載字型檔。內文 15px、表格與控制項 14px，畫面上沒有小於 12px 的字；數字一律等寬（tabular）。

間距

4px 格線，另有 2px 給細部對齊。卡片內距 20/24、區塊間距 16、頁面邊距 24/32。

圓角與陰影

標籤 6、按鈕與輸入框 8、卡片 12、對話框 16。陰影用側欄的墨綠色當底，深度看起來是同一種材質。

動態

動畫只用來說明「東西從哪裡來、到哪裡去」。進場比退場慢；最長 320ms；系統設定「減少動態」時全部改為瞬間完成。

--ease-enter / --ease-exit—進場減速、退場加速

圖示

24px 格、1.75 線寬、圓角端點（畫法沿用 Lucide，ISC 授權）。由 ICUIcons.svg(名稱) 產生；裝飾用的圖示對報讀軟體隱藏，只有圖示的按鈕一定要有 aria-label。

按鈕

沒加 class 的 <button> 是主要動作；一個區塊只放一顆。其他依序降為 secondary、tertiary；刪除與作廢用 danger。按鈕文字不換行。

表單

標籤在欄位上方，說明與錯誤在欄位下方。框線對白底 3:1；聚焦時藍色框線加外圈，與綠色的「選取」分開。

篩選、分段、頁籤

頁籤換「畫面」，用底線；分段控制換同一區塊的「檢視」，用白底浮起；篩選鈕縮小「資料範圍」，選取時打勾。三者外觀刻意不同，避免一頁三層長得一樣的頁籤。

狀態標籤

標籤只說狀態，不能點。顏色依語意：警示用琥珀、危險用紅、資訊用藍、DNR 用深色實底以免與一般標籤混淆。

提示與 Toast

提示（notice）放在內容裡、會一直留著，用來說明這一區的狀態。Toast 是剛做完的動作結果：從畫面下方浮出，成功 5 秒後淡出，錯誤留到按關閉或換頁。

使用規則

要

  • 新樣式先找 token；沒有合適的再提出新增，不要寫原始色碼或 px 字級。
  • 共用元件寫在 components.css；單一畫面的版面留在 app.css。
  • 只有圖示的按鈕加 aria-label 與 title（兩者都會被翻譯）。
  • 表格中的病人名、醫囑名用文字色連結，hover 才出底線。
  • 危險與警示同時給圖示或文字，不只靠顏色。

不要

  • 同一區塊放兩顆以上實心主色按鈕。
  • 把規格說明或操作說明長段寫在畫面上；說明放 PRD，畫面只留一句提示。
  • 用 !important 蓋掉元件；需要例外就在 components 層加一條有名字的變體。
  • 超過 320ms 的動畫，或為了好看而動的東西。
  • 新增第二套頁籤樣式；只有頁籤、分段、篩選三種。
